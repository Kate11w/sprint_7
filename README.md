## Проект автоматизации тестирования API сервиса "Яндекс.Самокат"

1. Основа для написания автотестов — фреймворк pytest.
2. Установить зависимости — pip install -r requirements.txt.
3. Команда для запуска — pytest -v.

### Описание тестов:
1. test_create_couriers.py - проверка создание курьера
2. test_login_courier.py - проверка авторизации курьера
3. test_create_order.py - проверка создания заказа
4. test_get_order_list.py - проверка полного списка заказов
